THE CONCEPTS

How DNS Works

DNS is the internet's distributed naming system: it helps applications find the IP address associated with a human-readable domain.

01

Recursive & iterative queries

A client asks a recursive resolver for a complete answer. On a cache miss, the resolver follows referrals: root to TLD to the domain's authoritative server.

02

Root, TLD & authority

Root servers direct the resolver to a top-level domain (such as .com); TLD servers point to the domain's authority, which provides its records.

03

A records, cache & TTL

An A record maps a name to an IPv4 address. Resolvers cache answers for their TTL (time to live), reducing repeated work until the entry expires.

04

NXDOMAIN

If the authoritative lookup says a domain name does not exist, the resolver returns NXDOMAIN. Failed results are not cached in this simulator.

ⓘ This application simulates DNS behavior for learning. It does not send DNS packets or perform live recursive resolution.
